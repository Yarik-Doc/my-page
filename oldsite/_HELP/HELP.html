Bluefolio Template Documentation

HTML STRUCTURE

The pages are built in 3 sections - .wrapper1, .main, .wrapper2


.wrapper1 holds the header which consists of #logo and .contact-info.

.main holds the main body of text and images.

.wrapper2 holds the footer and all relevant info.


Files

All neccessary HTML, CSS, Javascript and images are all contained within the downloaded .zip file.

The images in the website demo will not be included and blank image placeholders will be used instead. Just replace them with your own images.


CONTACT FORM

To get the form to send to your email address you have to add your email address to the "freecontactformsettings.php" file. I have put comments on that file so when you open it in your text editor you will easily be able to configure it. Will only take a minute to update.

If you change the Anti Spam Question on the form you will have to update the answer, also in the "freecontactformsettings.php" (Example below)

<?php

 

$email_to = "you@yourdomain.com"; // your email address goes in place of you@yourdomain.com. MAKE SURE THAT YOU LEAVE THE QUOTES ("") IN PLACE


$email_subject = "Contact Form Message"; // email subject line will show up on the received email.


$thankyou = "thankyou.html"; // thank you page shows once the form has been sent to let users know that the form is sent then redirects the user back to your homepage after 8/9 seconds

 

// if you update the Anti Spam question on the form -

// you need to update the questions answer below

$antispam_answer = "25";

 

?>

GOOGLE MAPS

To show your location on the Google Map you have to change the lat and long co-ordinates in the "contact.html" file. (LINE 71 - Long and Lat in RED text)

To get your location Lat and Long go to http://itouchmap.com/latlong.html and enter your address.


CSS Files

3 CSS files are included. ( main.css - flexslider.css & less.css)
I recommend leaving the "flexslider.css" unless you want to add direction buttons to the slider. I have included the main styling elements for the slider in the "main.css" file with the exception of the direction buttons.

Everything else is styled within the "main.css."

The less.css controls the page layout if someone is using a Tablet or Mobile to view your website


TIP : "before editing any files make sure you have a backup copy of the originals. Although you can always download them again if you mess anything up." ^__^


IMAGES

Image widths are controlled with CSS. To ensure your images look sharp it is IMPORTANT to make your images to the highest required dimensions.
"EXAMPLE" - The slider on the home page is 980px wide. Currently the image is half the size of the slider so you need to make sure that your slider images are a minimum width of 490px. If you want your images to take up the full width of the slider then they will have to be a minimum width of 980px and you will have to also alter the image width in the "main.css" file. It is currently set to 50% so you would change that to 100%. No need to set image height as this is taken care of elsewhere.

Best to make all your images the same dimensions as this stops the slider changing size and moving your page layout around.

 

The images on the portfolio page will be at their largest size on a mobile layout in landscape. This is currently set at 460px in the "less.css" file so make sure images that you are using for those are at least 460px wide.

 

The images in the blog post are simple resized slider images all taken care of for you by setting the image size in .column-large div to 100%.


SOCIAL ICONS

To link these to your Social Media Accounts simply replace our relevant URL's with URL's to your own Social Accounts


SOCIAL SHARING BUTTONS

Google Plus 1 button will share the pages URL. No need to edit this.

Facebook Like & Twitter Share / Follow buttons can be obtained from their websites. Simply replace our buttons with your own. The facebook button has a linked piece of Javascript up in the <head> of the document and the Twitter buttons come with their own javascript which you will see is beside the links in the HTML of the page.

These are also styled in the "main.css" although the styling is only to align the buttons. You can't change how they look.


JAVASCRIPT

All the relevant Javascript files are linked at the bottom of each page. This lets them load last on your page enabling visitors to see your content quicker. I recommend leaving the Javascript files as they are.

The final Javascript entry on each page is where you edit the Twitter Feed and the Flexslider. (Flexslider is only on home page but Tweet Feed is on every page so make sure you replace our Twitter ID with your Twitter ID on all pages. Again I have left comments on the pages explainig exactly how to edit. (Example below) You can also style the tweets in the "main.css"

<script>
jQuery(document).ready(function($) {

$('.flexslider').flexslider({
animation: "fade",
controlNav: false,
keyboardNav: true,
directionNav: false
});

// TWITTER WIDGET //
$("#tweets").tweet({
count: 3, //HOW MANY TWEETS YOU WANT ON SHOW//
username: "esksidedesign"//REPLACE WITH YOUR TWITTER ID AND LEAVE THE ( "" )IN PLACE//
});

//close
});
</script>
